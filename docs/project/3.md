# 입자가속기의 발전과 하전입자의 상대론적 운동 이해

<div stye="margin-top: 37px;"></div>

물리학2에서 배우는 전기장을 공부하고 입자가속기의 원형인 선형가속기에 대해 공부한 후 원형과의 비교를 통해 학습합니다. 원형가속기의 원형인 베타트론과 사이클로트론을 공부하고 최종적으로 싱크트론을 공부합니다. 후에 입자가속을 시뮬레이션으로 돌려봅니다. 이 과정에서 전자기장, 상대론적 입자 운동 등을 공부하고 논문 읽는 법을 학습하고 유럽의 cern에 대해 알아봅니다.
